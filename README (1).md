# Machining Sounds Lesson Series

Workshop notebooks (Parts A through C), companions to *Machining Dynamics: Jupyter Notebook Edition*.

- **Part A — Vibrations**
- **Part B — Sound**
- **Part C — Machining**

## Running the notebooks

Launch the notebooks in your browser via Binder (no installation required). After the notebook opens, run all cells: **Run → Run All Cells**.

To run locally instead, install the dependencies with `pip install -r requirements.txt` and open the notebooks in Jupyter.
